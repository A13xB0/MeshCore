Entry repeaters

Channel messages by the repeater they got onto the mesh through (the first hop of their path). Block a spammer's entry repeater and its channel messages are not repeated here or passed to AirLink phones; direct messages, acks and adverts still go through. A path with 1-byte hashes only shows the first byte, so it is matched on that.

Trace a path

The trace visits each hop in turn and every hop records the signal it received it at. "And back" returns along the same hops so the result reaches this repeater. IDs are the first 3 bytes of a node's public key; a trace hop is the first 1, 2 or 4 bytes (the graph above uses 1). Tap + in the Nearby list to add a node.

Check for updates first.
The repeater downloads the firmware itself, verifies its sha256 against the manifest, writes it to the spare firmware slot and reboots into it. Identity, settings and network configuration are kept. The repeater checks for updates by itself a few times a day.

Manual upload (legacy)

The original OTA page is still at /update: pick a MeshOS repeater firmware file from your computer. It uses the web password from the last boot.
